# Testes Funcionais e Checklists – Urban Routes (Sprint 3 – TripleTen)

Projeto desenvolvido durante o 3º Sprint do Bootcamp de QA da TripleTen, com foco em testes funcionais, validação de interface, criação de checklists e documentação de bugs no Jira.


## 🎯 Objetivo do Projeto
Garantir a qualidade das principais funcionalidades do aplicativo Urban Routes por meio de:
- Validação de layout e elementos visuais
- Testes funcionais de fluxos críticos
- Verificação de regras de negócio
- Análise de comportamento de botões e interações
- Registro estruturado de bugs


## 🧪 Escopo do Projeto

### **1. Checklist de Layout**
- Conferência de elementos visuais
- Alinhamento, cores, ícones e responsividade
- Identificação de inconsistências de UI

### **2. Checklist de “Método de Pagamento” e “Adicionar Cartão”**
- Validação de campos obrigatórios
- Regras de preenchimento
- Mensagens de erro
- Comportamento dos botões

### **3. Casos de Teste – Botão “Reservar”**
- Testes funcionais do fluxo de reserva
- Cenários positivos e negativos
- Evidências de execução

### **4. Casos de Teste – Locação**
- Validação do fluxo de locação
- Regras de negócio
- Entradas válidas e inválidas

### **5. Relatórios de Bug no Jira**
- Descrição detalhada
- Passos para reproduzir
- Resultado esperado vs. obtido
- Priorização e categorização
